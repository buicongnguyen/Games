# Games

This repository publishes **Sky Drill** at the repo root and **Sky Drill 2** under `skydrill2/`.

## Play Online

- [Sky Drill 2](https://buicongnguyen.github.io/Games/skydrill2/) — physics-correct rebuild: exact trajectory preview, real ballistics/restitution, structural collapse, full story campaign
- [Sky Drill](https://buicongnguyen.github.io/Games/) — the original prototype
- [Tetris Classic](https://buicongnguyen.github.io/tetris-classic/)

## Repository Layout

- `index.html`, `styles.css`, `src/`, `assets/`: Sky Drill (version 1)
- `skydrill2/`: Sky Drill 2 (source repo: [buicongnguyen/SkyDrill2](https://github.com/buicongnguyen/SkyDrill2))
- `SKY-DRILL.md`: Sky Drill notes and chapter summary

## Local Run

1. Open the repo root `index.html` to run Sky Drill, or `skydrill2/index.html` for Sky Drill 2.
2. The Tetris build now lives in its own repository: `C:\Users\n\source\repos\tetris-classic`
