# Games

This repository publishes **Sky Drill** as the main game at the repo root.

## Play Online

- [Sky Drill](https://buicongnguyen.github.io/Games/)
- [Tetris Classic](https://buicongnguyen.github.io/tetris-classic/)

## Repository Layout

- `index.html`, `styles.css`, `src/`, `assets/`: Sky Drill
- `SKY-DRILL.md`: Sky Drill notes and chapter summary

## Local Run

1. Open the repo root `index.html` to run Sky Drill.
2. The Tetris build now lives in its own repository: `C:\Users\n\source\repos\tetris-classic`
